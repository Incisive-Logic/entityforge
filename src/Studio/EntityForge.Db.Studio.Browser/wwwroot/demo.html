Open Studio above: the connection is ready for you. In Builder, set Find to Person. Open Return, check All Properties, and select Run Query. For the exact examples here, expand Show query, copy a GraphQL query, then use Studio’s GraphQL mode. Native Semantic GQL and SPARQL are available in this tour and over HTTP; Studio’s Semantic editor currently offers Builder and GraphQL.

This sample is rebuilt from source data on every launch and removed on normal shutdown. Stop the server with Ctrl+C. The sample does not open or alter your existing databases. Keep the launch link local: it contains temporary read access.
