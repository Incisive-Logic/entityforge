# Code of conduct

The [community conduct policy](docs/db/CODE_OF_CONDUCT.md) applies to participation
in this repository. Treat others respectfully, discuss ideas and evidence, and do
not harass people or disclose their private information.

If a private reporting channel is not available, ask a maintainer for one without
including sensitive details in a public issue. Security vulnerabilities should
follow the [security policy](SECURITY.md).
