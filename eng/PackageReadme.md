# EntityForge

EntityForge provides a .NET database with semantic, property-graph and RDF profiles, HTTP clients and shared contracts. EntityForge DB Studio is its browser interface.

This package is part of the EntityForge library set. Use client/profile packages as application entrypoints; storage and engine packages primarily support advanced integrations or transitive deployment.

The software is pre-release. APIs and storage formats may change. Original project code is licensed under Apache-2.0; included third-party notices and dependency licences still apply.
