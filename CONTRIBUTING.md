# Contributing to EntityForge

Start with the [contribution guide](docs/db/CONTRIBUTING.md),
[build instructions](docs/developer/building.md) and
[architecture overview](docs/developer/architecture.md).

Report reproducible bugs and suggest improvements through
[GitHub issues](https://github.com/Incisive-Logic/entityforge-db/issues).
Include the version, profile, deployment and a minimal example using synthetic data.
Use the [security policy](SECURITY.md) for vulnerabilities, not public bug reports.

For changes, open a focused pull request with an explanation, appropriate tests and
updated documentation. Record notable user-visible changes under **Unreleased** in
[CHANGELOG.md](CHANGELOG.md). Preserve third-party licences and notices.

Follow the [code of conduct](CODE_OF_CONDUCT.md). The [FAQ](docs/faq.md) describes
the project's use of AI assistance and how to interpret validation evidence.
